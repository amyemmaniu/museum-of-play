## Description

The gallery begins empty. Over the course of ten weeks, it fills with the work of a single program.

For *CODE{X}*, artist Rhiannon Alarie wrote a set of scripts that generate projections, sound, and kinetic sculpture inside a blank white room. Each day, the code reads from inputs such as the weather, visitor counts, and the time, and produces a new composition that will never appear again.

Alarie's source code is printed on the walls and updated daily, so visitors can trace how a line of logic becomes a shape or a note. Part artwork and part instruction manual, *CODE{X}* treats programming as a form of play: a way of making rules and then watching what they do.

## How to visit

- No programming experience is needed
- Free coding workshops are held on select Saturdays; see the events calendar
